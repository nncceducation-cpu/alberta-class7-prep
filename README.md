# Alberta Class 7 Knowledge Test Prep

Interactive flashcards (160), road-sign trainer (24 signs), and five full 30-question practice exams for the Alberta Class 7 learner's knowledge test — built from the official Alberta Driver's Guide (Spring 2026).

**Live site:** enable GitHub Pages (Settings → Pages → Deploy from branch → main, / root) and share the URL.

Everything is a single `index.html` — no build step, no dependencies. Progress and best scores are saved in the browser.

Independent study resource; not affiliated with the Government of Alberta. Verify rules at [Alberta.ca](https://www.alberta.ca/driver-guides.aspx).
